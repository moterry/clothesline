## 1. Intent

After a `⌘⇧4` screenshot, a floating thumbnail sits in the bottom-right corner for a few seconds. Drag it away and the screenshot goes where it is needed. Leave it, and it stays on the Desktop. Over time the Desktop fills up and a screenshot from a few days ago becomes hard to find.

Clothesline catches every screenshot that was not dragged away and hangs it neatly, like laundry, on a thin line across the top of the desktop. When the line is full, or the day ends, the whole line is rolled into a bundle and drifts into a river along the bottom of the desktop. It is kept there forever, until you yourself release it into Lethe.

The tool should feel **artistic, literary and philosophical while staying very simple**, with a design language drawn from ancient Greece and Rome.

### Three core images

| Part | Time | Source | Meaning |
|---|---|---|---|
| **The Clothesline** | the present | The three Fates: Clotho spins the thread, Lachesis measures it, Atropos cuts it | Today's screenshots hang on a freshly spun line. The line has a limited length and is cut when full or at midnight |
| **The River of Memory** | the past | Mnemosyne, the spring of memory in the underworld; Plato's *anamnesis* (learning as recollection) | Old screenshots drift downstream in bundles and grow fainter with age. When the mouse comes near, a bundle regains its color, as if remembered |
| **Lethe** | letting go | Lethe, the river of forgetting; the Stoic "everything flows, hold nothing too tightly" | Only screenshots you put there yourself sink and are permanently deleted |

### What success looks like

- Screenshot files never pile up on the Desktop again.
- To find a screenshot from a few days ago, you reveal the desktop, glance along the river, recognize it **by its thumbnail** and have it in hand within seconds.
- It is quiet, beautiful and almost invisible.

## 2. Goals, non-goals, anti-goals

**Goals**
- Automatically catch every system screenshot that was not dragged away and hang it on the line.
- Keep old screenshots forever in the river, in time order, findable by thumbnail.
- Let screenshots on the line and in the river be dragged straight into other apps (chat windows and so on).
- Present all of this in a restrained, classical visual language.

**Non-goals (not in v1)**
- Text search, OCR, tags, categories
- Annotating, cropping or editing screenshots
- Cloud sync or multiple devices
- Handling screen recordings (`.mov`)
- Multiple displays (main display only) [Claude's call]
- Replacing the system screenshot tool: system screenshots work as usual, Clothesline only catches them

**Anti-goals (failure even if it technically works)**
- A cluttered interface that feels like a file manager
- Stealing focus, appearing in the Dock or `⌘Tab`, covering the windows you are working in
- **Any screenshot disappearing without your own hand acting on it**
- Breaking the existing habit of dragging a screenshot straight from the floating thumbnail

---

## 3. Constraints

- Runtime: macOS 26.2 on Apple silicon.
- Tooling: **Xcode is not installed**. Only the Command Line Tools are present (Swift 6.3.3 + Swift Package Manager). Compiling a program that uses AppKit, SwiftUI and ServiceManagement has been confirmed to work.
- A native macOS app written in Swift. It is built with SwiftPM, packaged by a script into `晾衣绳.app` (Clothesline.app) and ad-hoc signed on this Mac. On first launch the user may need to click "Open Anyway" in System Settings → Privacy & Security.
- Runs entirely locally, with no network access.
- The user's wallpaper is **light**. The Desktop has some files and folders; the user will tidy them up and arrange them so they do not overlap the line or the river.
- The user reveals the desktop with the **four-finger spread gesture** or **`F11`**.

---

## 4. Lifecycle

```
Screenshot (⌘⇧3 / ⌘⇧4 / ⌘⇧5) → floating thumbnail, bottom-right (a few seconds)
    ├─ dragged away → went where you wanted; the system saves no file; Clothesline does nothing
    └─ not dragged → the system saves the file into Clothesline's folder → it floats up onto the line (present)
                       └─ line full OR local midnight → cut, rolled into a bundle → River of Memory (past, forever)
                                                          └─ only by your hand → Lethe (rescuable for a few seconds, then permanently deleted)
```

## 5. Detailed behavior

### 5.1 Catching screenshots

- On first launch, a short, well-designed explanation asks for consent to change the system screenshot save location to Clothesline's folder: `~/Pictures/Clothesline/` [Claude's call: an English path, because some tools handle non-ASCII paths badly].
  - This is equivalent to `defaults write com.apple.screencapture location <path>`, restarting SystemUIServer if needed for the setting to take effect.
  - The original location is remembered. The menu bar offers "Restore system screenshot location".
- The app continuously watches that folder. A new image file appearing there means a screenshot was not dragged away, so it is hung on the line.
  - The system first writes a hidden temporary file and then renames it, so ignore files starting with `.` and wait until the file is fully written.
  - Only image formats count (png, plus jpg / heic / tiff / pdf if the user changed the format). `.mov` screen recordings are ignored.
- "Capture to clipboard" screenshots such as `⌃⌘⇧4` create no file and so never reach the line. That is correct.
- If the user has turned off the system's "Show Floating Thumbnail", screenshots are saved immediately and so go onto the line immediately.

### 5.2 The Clothesline: the present

**Position and look**
- At the top of the main display, just below the menu bar, spanning almost the full screen width.
- The line is a naturally sagging catenary (a quadratic Bézier approximation is fine), about 1pt wide.
- Above the left end of the line, today's date in a faint inscriptional typeface: `HODIE · XIV · XI` (day · month, in Roman numerals).

**How screenshots hang**
- Left to right in time order. Each new one takes the rightmost empty slot.
- Keep each screenshot's original aspect ratio, so portrait stays portrait. Maximum height about 120pt, maximum width about 150pt.
- Each screenshot has a 3pt white border, a soft shadow and a small bronze peg at the top.
- Each screenshot tilts slightly to follow the slope of the line, plus a small random angle (±1.5°) so it looks hand-hung. The random angle is fixed per screenshot and does not change on refresh.
- When a screenshot arrives, it floats from the bottom-right corner (where the system thumbnail was) along an arc to its slot, in about 1 second, with ease-in and ease-out.

**Line length and cutting**
- One line holds at most **12 screenshots** [Claude's call; the menu lets you choose 8 / 12 / 16].
- The line is cut on whichever comes first: **it is full**, or **local midnight**. If, at launch, the line holds screenshots from a previous day, it is cut immediately.
- When cut, the whole line rolls into a bundle and drifts to the left end of the river, and a fresh, empty line is spun from the left. The animation takes about 2 seconds.
- Empty slots show no placeholder; empty is simply empty [Claude's call].

**Interaction** (the same for screenshots on the line and in the river)
- **Hover**: an enlarged preview, about 2×, floating near the original position.
- **Click**: open in Quick Look.
- **Drag**: drag out as a file, straight into a chat window, email, Finder and so on. **After dragging, the screenshot stays where it was.**
- **Right-click menu**: Quick Look / Show in Finder / Copy / Sink into Lethe.

### 5.3 The River of Memory: the past

**Position and look**
- At the bottom of the main display, above the Dock, spanning the full screen width, about 130pt tall.
- The river is a very faint blue-grey band whose top and bottom edges fade out, with a few fine white glints in it. It may have a very slight sense of flow.
- The left end is labeled `ΜΝΗΜΟΣΥΝΗ` (memory), the right end `ΛΗΘΗ →` (Lethe).

**Bundles**
- One cut line becomes one bundle.
- A bundle is drawn as up to 3 screenshots stacked slightly askew (the first 3 in the bundle), with the date below in the inscriptional typeface: `XIII · XI`.
  - When one day has several bundles, add an ordinal: `XIV · XI · I`, `XIV · XI · II`.
  - For a past year, add the year in Roman numerals: `XIV · XI · MMXXV` [Claude's call].
- The newest bundle is at the far left, older ones further right.
- **Kept forever**: the river never deletes anything by itself.

**Fading and recollection**
- Older means fainter and greyer: opacity and saturation decrease with age in days, reaching a floor at about 30 days (opacity about 0.45, saturation about 0.15) and fading no further [Claude's call]. Even the oldest screenshot must still show its content.
- **Hovering over a bundle**: it rises, grows to about 1.3×, regains full color, gains a faint golden glow, and `ἀνάμνησις · 回忆` briefly appears above it.

**Browsing and taking**
- The river can be endlessly long. With the pointer over the river, scrolling horizontally with the wheel or trackpad moves back through time.
- **Clicking a bundle**: it unrolls above the river like a scroll and shows every screenshot in it. Each one behaves exactly like a screenshot on the line (hover, click, drag out, right-click). Click elsewhere or press `Esc` to roll it back up.
- When the river holds many screenshots, thumbnails must load on demand so nothing stutters.

### 5.4 Lethe: letting go

- **A screenshot enters Lethe only through your own action.**
- How to send something there [Claude's call]:
  - **Drag it in**: while dragging any screenshot (or a whole bundle), a dark patch of water appears at the river's right end, at `ΛΗΘΗ`. Drop it there and it sinks into Lethe: it flows downstream into forgetting.
    - This replaces the earlier idea of "dragging it down out of the river". Dragging is also how screenshots go into other apps, so a downward drag is easy to misread; a clear drop target avoids that.
  - **Right-click → Sink into Lethe**.
- **Sinking**: over about **5 seconds** the screenshot slowly sinks and fades, with ripples on the water.
  - During those seconds, clicking it or dragging it out **rescues** it and returns it to where it was.
  - After 5 seconds it has fully sunk: the file is **permanently deleted**, not moved to the Trash.
  - The deletion is performed only at the moment the 5 seconds end. If the app quits or crashes during that time, the screenshot counts as rescued and is not deleted.
- Sinking a whole bundle deletes every screenshot in it.

### 5.5 When it is visible

- The line and the river live **at the desktop layer**: above the wallpaper and below every app window. Normally they are covered by windows and become visible and clickable only when the desktop is revealed. The user does this with the four-finger spread gesture or `F11`.
- **Priority (decided by the user): if "visible only on the desktop" conflicts with "drag a screenshot straight into another app", dragging into apps wins.**
  - First verify: with the desktop revealed, when a screenshot is dragged from the line or the river, do the pushed-aside windows come back so it can be dropped into a chat window?
  - If not, enable **summon**: a global hotkey (default `⌃⌥L`, L for Linea [Claude's call]) or "Summon Clothesline" in the menu bar menu temporarily raises the line and the river above all windows. Screenshots can then be dragged into any visible window behind them. `Esc`, pressing the hotkey again, or completing a drop sends them back to the desktop layer.
  - Summoning happens only when you ask for it, so it does not count as stealing focus. Even if dragging works in desktop mode, summon stays, as a quick way to grab a screenshot without revealing the desktop [Claude's call].
- Not shown in the Dock, `⌘Tab` or Mission Control's window list. Never steals focus. Shown on every Space.
- The line and the river are **two separate horizontal strip windows** covering only the top and bottom of the screen. The middle is left for desktop icons. Transparent areas must let mouse clicks through so they never block clicks on desktop icons.

### 5.6 Menu bar

- A very small menu bar icon (a thin arc). No Dock icon.
- Menu items [Claude's call]: Summon Clothesline (`⌃⌥L`) · Pause / Resume catching · Open screenshot folder · Line length (8 / 12 / 16) · Launch at login · Restore system screenshot location · Quit.
- Launch at login is on by default, using the system login-item mechanism.
- [Claude's call] What the two switches mean exactly (principle: no screenshot is ever lost, whatever the state):
  - **Pause catching**: screenshots are still saved into the root of `~/Pictures/Clothesline/` but are not hung on the line for now. On "Resume", everything saved in the meantime is hung in time order, cut into bundles by the usual rules if it exceeds the line length.
  - **Restore system screenshot location**: sets the system screenshot location back to where it was (usually the Desktop). Clothesline stops catching new screenshots, but the line and the river stay visible and usable. The menu item then becomes "Catch screenshots again", which asks for consent again and changes the location back.

### 5.7 First launch

1. One short explanation page (the three lines: line · river · Lethe), asking for consent to change the screenshot save location.
2. [Claude's call] Ask whether to gather **existing screenshots on the Desktop** into the river: recognize them by file name (for example `截屏 2026-…` or `Screenshot …`) and bundle them by their own dates, one bundle per day (split into several if a day exceeds the line length). The files are **moved** into the river, not copied, so the Desktop really ends up clean. The user may decline.
3. Start working, with an empty line.

## 6. Data and storage

**The folder structure is the state** [Claude's call]. There is no database, and screenshots can be found directly in Finder:

```
~/Pictures/Clothesline/
├── (system screenshots land here first; the app immediately moves them into Rope/)
├── Rope/                       ← screenshots on today's line
└── River/
    ├── 2026-11-14 · II/        ← one folder per bundle
    ├── 2026-11-14 · I/
    └── 2026-11-13 · I/
```

- Order on the line: by file creation time.
- Order of bundles: by the date and ordinal in the folder name.
- Sinking into Lethe: delete the file; if its folder becomes empty, delete the folder too.
- Small extra state, such as each screenshot's fixed random tilt, can live in a hidden JSON file. Losing that file never affects any screenshot.

## 7. Visual specification (light wallpaper)

| Element | Spec |
|---|---|
| Line | `#4a4540`, about 1.1pt, round caps |
| Peg | bronze `#9a7b4f`, small 6×17pt rounded rectangle |
| Screenshot frame | 3pt white border, soft shadow (3pt down, about 20% black) |
| Date / label text | `#7a7268`, inscriptional capital serif, wide letter spacing |
| River water | `#4f6f8f`, about 16% opacity at the center, fading to 0 at top and bottom |
| River glints | fine white lines, 15%–50% opacity |
| River text | `#8a7650`; hover highlight `#9a7b3c` |
| Recollection glow | `#e8c77a`, about 8pt soft glow |

- **Typeface**: Latin and Greek letters use an inscriptional classical serif (in the spirit of Cinzel) that must also cover Greek. Cinzel itself may lack Greek glyphs, so pair it with or replace it by a suitable open-source font, bundled with the app. Chinese uses the system Song typeface (Songti SC).
- **All dates in Roman numerals.**
- Keep decoration restrained: no ornamental borders, no gradient buttons, no decorative icons. The interface should be almost invisible.
- [Claude's call] v1 ships only the light palette. Automatically switching to a dark palette based on wallpaper brightness (the dark version in the sketch) is left for later.

## 8. Left to the builder

- Exact animation curves, durations and physical feel (for example a slight swing after a screenshot lands on the line)
- The exact window level and technique that keep desktop-layer windows below every app window while still receiving mouse events
- How file watching is implemented
- Thumbnail generation and caching (for example QuickLookThumbnailing)
- Performance when the river holds thousands of screenshots
- Code structure, and where to use SwiftUI versus AppKit
- How the packaging script is written

## 9. Known risks

- **Interaction with desktop-layer windows**: the system restricts mouse events for desktop-layer windows. Build a minimal proof of concept first, covering three things: with the desktop revealed by the four-finger spread or `F11`, can the strips be clicked, can a screenshot be picked up, and can it then be dropped into another app? The result decides whether summon becomes the main way to take screenshots out (see 5.5). The user did not mention using Stage Manager, so v1 does not specifically support it.
- **Permission prompts**: reading and writing `~/Pictures`, and `~/Desktop` when importing old screenshots, may trigger system access prompts.
- **Permanent deletion is irreversible**: the only safety net is the 5-second rescue window, so that part must be reliable.
- **Changing the system screenshot location**: if Clothesline is not running, screenshots pile up in the root of `~/Pictures/Clothesline/`. On the next launch they must all be hung on the line (cut into bundles by the usual rules if they exceed the line length).
