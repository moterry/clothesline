## 1. 意图

用 `⌘⇧4` 截完图后，右下角会出现几秒浮窗。拖走了，截图就去了该去的地方；没拖走，它就留在桌面上。截图一多，桌面就满了，几天前的截图也找不到。

「晾衣绳」接住所有没被拖走的截图。它们像衣服一样，整齐地挂在桌面上方的一根细绳上。绳挂满了，或者一天过去了，整根绳就卷成一束，流进桌面下方的一条河里，永久保存，直到你亲手把它放进忘川。

整个工具要**有艺术感、文艺感、哲学感，同时非常简洁**，设计语言取自古希腊、古罗马。

### 三个核心意象

| 部分 | 时间 | 来源 | 含义 |
|---|---|---|---|
| **晾衣绳** | 现在 | 命运三女神：克洛托纺线、拉刻西斯量长、阿特洛波斯剪断 | 今天的截图挂在一根新纺的绳上；绳长有限，挂满或到了午夜就剪下 |
| **记忆之河** | 过去 | 冥界的记忆之泉 Mnemosyne；柏拉图的「回忆说」(anamnesis) | 旧截图按束顺流排开，越旧越淡；鼠标靠近，它就恢复原色，即"想起" |
| **忘川** | 放下 | 忘川 Lethe；斯多葛派的"万物流转、不必执着" | 只有你亲手放进去的截图会沉没、被永久删除 |

### 怎样算成功

- 桌面上再也不会堆积截图文件。
- 想找几天前的截图时，露出桌面，扫一眼河，**靠缩略图内容**几秒钟就能认出并拿到它。
- 它安静、美，几乎感觉不到存在。

## 2. 目标、非目标、反目标

**目标**
- 自动接住所有没被拖走的系统截图，挂到绳上。
- 旧截图永久保存在河里，按时间排列，靠缩略图就能找。
- 绳和河里的截图都能直接拖进其他应用（聊天窗口等）使用。
- 用一种克制的、古典的视觉语言把这一切呈现出来。

**非目标（第一版不做）**
- 文字搜索、OCR、标签、分类
- 标注、裁剪、编辑截图
- 云同步、跨设备
- 屏幕录制（`.mov`）的处理
- 多显示器（只在主显示器上显示）【我的决定】
- 取代系统截图工具：系统截图照常工作，晾衣绳只负责"接住"

**反目标（做到了也算失败）**
- 界面变得繁杂，像一个文件管理器
- 抢焦点、出现在 Dock 或 `⌘Tab` 切换里、挡住正在用的窗口
- **任何截图在你没有亲手操作的情况下丢失**
- 破坏"从浮窗直接拖走截图"这个原有的习惯

## 3. 约束

- 运行环境：macOS 26.2，Apple 芯片。
- 开发工具：Mac 上**没有安装 Xcode**，只有命令行开发工具（Swift 6.3.3 + Swift Package Manager）。已确认可以编译使用 AppKit、SwiftUI、ServiceManagement 的程序。
- 原生 macOS 应用，Swift 编写。用 SwiftPM 编译，再用脚本打包成 `晾衣绳.app`，本机自签名（ad-hoc）。第一次打开时，可能需要在"系统设置 → 隐私与安全性"里点"仍要打开"。
- 完全本地运行，不联网。
- 用户的壁纸是**浅色**的。桌面上有一些文件和文件夹，用户会自己整理，把它们摆到不挡绳和河的位置。
- 用户平时用**四指张开手势**或 **`F11`** 露出桌面。

## 4. 生命周期

```
截图（⌘⇧3 / ⌘⇧4 / ⌘⇧5）→ 右下角系统浮窗（几秒）
    ├─ 被拖走 → 去了你要去的地方，系统不保存文件，晾衣绳什么都不做
    └─ 没被拖走 → 系统把文件存进晾衣绳的文件夹 → 飘上绳（现在）
                       └─ 挂满 或 到了午夜 → 剪断，卷成一束 → 记忆之河（过去，永久）
                                                   └─ 只有你亲手 → 忘川（几秒内可捞回，之后永久删除）
```

## 5. 详细行为

### 5.1 接住截图

- 第一次启动时，用一个简短、好看的说明页征求同意，把系统截图的保存位置改到晾衣绳的文件夹：`~/Pictures/Clothesline/`【我的决定：路径用英文，避免某些工具不认中文路径】。
  - 做法相当于 `defaults write com.apple.screencapture location <路径>`，必要时重启 SystemUIServer 让设置生效。
  - 记住原来的保存位置。菜单栏里提供"恢复系统截图位置"。
- 程序持续监视这个文件夹。有新图片文件出现，就是一张没被拖走的截图，挂到绳上。
  - 系统写文件时会先生成隐藏的临时文件再改名，要忽略以 `.` 开头的文件，并等文件写完整再处理。
  - 只认图片格式（png，以及用户可能改成的 jpg / heic / tiff / pdf）。`.mov` 屏幕录制忽略。
- `⌃⌘⇧4` 这类"截到剪贴板"的截图不会产生文件，也就不会上绳，这是正确的行为。
- 如果用户关掉了系统的"显示浮动缩略图"，截图会立刻存成文件，也就立刻上绳。

### 5.2 晾衣绳：现在

**位置与外观**
- 在主显示器顶部、菜单栏下方，横跨几乎整个屏幕宽度。
- 绳的形状是自然下垂的悬链线（用二次贝塞尔曲线近似也可以），线宽约 1pt。
- 绳的左端上方，用碑铭字体淡淡写着今天的日期：`HODIE · XIV · XI`（日 · 月，罗马数字）。

**截图怎么挂**
- 从左到右按时间顺序排，新的挂在最右边的空位。
- 保持截图原来的长宽比，竖的就是竖的。高度上限约 84pt，宽度上限约 105pt（实测后按用户要求比最初的 120/150 缩小 30%）。
- 每张截图带 3pt 白边和柔和阴影，顶部一个青铜色小夹子。
- 截图顺着绳的坡度略微倾斜，再加一点随机角度（±1.5°），让它看起来是手挂上去的。随机角度对每张截图固定，不会每次刷新都变。
- 截图上绳时，从屏幕右下角（系统浮窗的位置）沿一条弧线飘到空位，约 1 秒，缓入缓出。

**绳长与剪断**
- 一根绳最多挂 **12 张**【我的决定；菜单里可以改成 8 / 12 / 16】。
- 两种情况会剪断绳子，哪个先到就按哪个：**挂满**，或者**到了本地时间午夜**。程序启动时如果发现绳上是前一天的截图，也立刻剪断。
- 剪断时：整根绳卷成一束，流进河的最左端，然后从左边纺出一根新的空绳。动画约 2 秒。
- 空位不画占位框，空着就是空着【我的决定】。

**交互**（绳上和河里的截图都一样）
- **悬停**：放大预览，约 2 倍大，浮在原位置附近。
- **单击**：用系统"快速查看"（Quick Look）打开。
- **拖动**：作为文件拖出去，可以直接拖进聊天窗口、邮件、Finder 等。**拖出去之后截图仍然留在原处。**
- **右键菜单**：快速查看 / 在 Finder 中显示 / 拷贝 / 沉入忘川。

### 5.3 记忆之河：过去

**位置与外观**
- 在主显示器底部、Dock 上方，横跨整个屏幕宽度，高约 130pt。
- 河是一道很淡的青灰色水带，上下边缘渐隐，里面有几道细碎的白色反光，可以有极轻微的流动感。
- 左端标 `ΜΝΗΜΟΣΥΝΗ`（记忆），右端标 `ΛΗΘΗ →`（忘川）。

**束**
- 一根被剪下的绳就是一束。
- 每束显示为最多 3 张截图错落叠在一起的样子（取这束里最前面的 3 张），下方用碑铭字体标日期：`XIII · XI`。
  - 同一天有多束时，加序号：`XIV · XI · I`、`XIV · XI · II`。
  - 不是今年的，加罗马数字年份：`XIV · XI · MMXXV`【我的决定】。
- 最新的一束在最左边，越往右越旧。
- **永久保存**：河不会自动删除任何东西。

**淡化与回忆**
- 越旧越淡、越灰：透明度和饱和度随天数降低，约 30 天降到下限（透明度约 0.45，饱和度约 0.15），之后不再变淡【我的决定】。再旧的截图也必须能看出内容。
- **悬停在一束上**：它浮起来，放大约 1.3 倍，恢复原色，带一圈淡金色微光，上方短暂出现 `ἀνάμνησις · 回忆`。

**浏览与取用**
- 河可以无限长。鼠标放在河上，用滚轮或触控板横向滚动，就是在时间里往回走。
- **单击一束**：它在河的上方展开，像书卷一样摊开，显示这束里的每一张。每一张的交互和绳上完全一样（悬停、单击、拖出、右键）。点空白处或按 `Esc` 收起。
- 河里的截图很多时要按需加载缩略图，不能卡。

### 5.4 忘川：放下

- **只有你亲手操作，截图才会进入忘川。**
- 进入方式【我的决定】：
  - **拖进去**：拖动任意截图（或一整束）时，河的右端 `ΛΗΘΗ` 处会浮现一片暗色水面。拖到那里松手，截图就沉入忘川，意思是"顺流而下，流进遗忘"。
    - 我改了之前说的"往下拖出河面"：拖动本来也用来把截图拖进别的应用，往下拖这个手势容易误判，所以改成一个明确的落点。
  - **右键 → 沉入忘川**。
- **沉没**：截图在约 **5 秒**里慢慢下沉、变淡，水面泛起涟漪。
  - 这几秒内点它，或者把它拖出来，就**捞回**，回到原来的位置。
  - 5 秒后完全沉没：文件被**永久删除**，不进废纸篓。
  - 删除只在 5 秒结束的那一刻才真正执行。如果这期间程序退出或崩溃，截图视为被捞回，不删除。
- 整束沉入忘川，就是这一束里的全部截图一起删除。

### 5.5 什么时候看得见

- 绳和河都住在**桌面这一层**：在壁纸之上，所有应用窗口之下。平时被窗口挡住，只有露出桌面时才看得见、点得到。用户的方式是四指张开手势或 `F11`。
- **优先级（用户已定）：如果"只在桌面出现"和"把截图直接拖进其他应用"冲突，"拖进应用"优先。**
  - 先验证：露出桌面时，从绳或河上拖起一张截图，被推开的窗口会不会回来，让你放进聊天窗口。
  - 如果不能，就启用**召唤**：按一个全局快捷键（默认 `⌃⌥L`，L 取自 Linea【我的决定】），或者点菜单栏图标里的"召唤晾衣绳"，绳和河就临时浮到所有窗口前面。此时可以把截图拖进后面任意可见的窗口。按 `Esc`、再按一次快捷键、或者拖放完成后，它们退回桌面层。
  - 召唤只在你主动操作时发生，不算抢焦点。即使拖动在桌面模式下就能成功，召唤也保留，作为不用露出桌面就能快速取图的方式【我的决定】。
- 不出现在 Dock、`⌘Tab` 和调度中心的窗口列表里，不抢焦点。所有桌面空间（Spaces）都显示。
- 绳和河是**两个独立的横条窗口**，分别只盖住屏幕顶部和底部。中间留给桌面图标。透明的地方鼠标要能穿透，不能挡住桌面图标的点击。

### 5.6 菜单栏

- 菜单栏里一个很小的图标（一根细细的弧线）。没有 Dock 图标。
- 菜单项【我的决定】：召唤晾衣绳（`⌃⌥L`）· 暂停 / 继续接住截图 · 打开截图文件夹 · 绳长（8 / 12 / 16）· 开机启动 · 恢复系统截图位置 · 退出。
- 默认开机启动，用系统的登录项机制实现。
- 【我的决定】两个开关的确切含义（原则：任何状态下都不能丢截图）：
  - **暂停接住**：截图仍然存进 `~/Pictures/Clothesline/` 根目录，只是暂时不挂上绳。点"继续"后，攒下的截图按时间顺序一次补挂上去，超过绳长就按规则剪断成束。
  - **恢复系统截图位置**：把系统截图位置改回原来的地方（通常是桌面），晾衣绳不再接新截图，但绳和河照常显示、照常能用。这个菜单项随后变成"重新接住截图"，点它会再次征求同意并改回位置。

### 5.7 第一次启动

1. 一页简短的说明（就是"绳 · 河 · 忘川"这三句话），请求同意修改截图保存位置。
2. 【我的决定】询问是否把**桌面上现有的截图**一起收进河里：按文件名识别，比如 `截屏 2026-…`、`Screenshot …`；按各自的日期成束，每天一束（超过绳长就分成几束）。文件是**移动**进河里，不是复制，这样桌面才会真正变干净。可以拒绝。
3. 开始工作，绳上是空的。

## 6. 数据与存储

**文件夹结构就是状态**【我的决定】。不用数据库，在 Finder 里也能直接找到截图：

```
~/Pictures/Clothesline/
├── （系统截图先存到这里，程序马上把它挪进 Rope/）
├── Rope/                       ← 今天这根绳上的截图
└── River/
    ├── 2026-11-14 · II/        ← 每一束一个文件夹
    ├── 2026-11-14 · I/
    └── 2026-11-13 · I/
```

- 绳上的顺序：按文件创建时间。
- 束的顺序：按文件夹名里的日期和序号。
- 沉入忘川：删除文件；如果文件夹空了，连文件夹一起删除。
- 小的附加状态，比如每张截图固定的随机倾角，可以放在一个隐藏的 JSON 里。这个 JSON 丢了也不影响任何截图。

## 7. 视觉规范（浅色壁纸）

| 元素 | 规格 |
|---|---|
| 绳 | `#4a4540`，约 1.1pt，圆头 |
| 夹子 | 青铜色 `#9a7b4f`，6×17pt 圆角小矩形 |
| 截图边框 | 3pt 白边，柔和投影（向下 3pt，约 20% 黑） |
| 日期 / 标注文字 | `#7a7268`，碑铭式大写衬线体，字距宽 |
| 河水 | `#4f6f8f`，中心不透明度约 16%，上下渐隐为 0 |
| 河中反光 | 白色细线，不透明度 15%–50% |
| 河中文字 | `#8a7650`；悬停高亮 `#9a7b3c` |
| 回忆微光 | `#e8c77a`，约 8pt 柔光 |

- **字体**：拉丁和希腊字母用一款碑铭式古典衬线体（参考 Cinzel 的气质），必须同时覆盖希腊字母。Cinzel 本身可能没有希腊字母，需要搭配或换用合适的开源字体，打包进应用。中文用系统宋体（Songti SC）。
- **日期全部用罗马数字。**
- 装饰克制：不加花纹边框，不用渐变按钮，不加图标装饰。界面要做到几乎看不见。
- 【我的决定】第一版只做浅色配色。按壁纸明暗自动切换深色配色（草图里深色那一版）留作以后再做。

## 8. 留给开发者决定

- 动画的具体曲线、时长和物理感（比如截图上绳后的轻微摆动）
- 让桌面层窗口既在所有窗口之下、又能接收鼠标的具体窗口层级和实现手法
- 文件监视的实现方式
- 缩略图的生成与缓存（例如 QuickLookThumbnailing）
- 河里截图上千张时的性能方案
- 代码结构，以及 SwiftUI 和 AppKit 各用在哪里
- 打包脚本的具体写法

## 9. 已知风险

- **桌面层窗口的交互**：系统对桌面层窗口接收鼠标事件有限制。开发初期应先做一个最小验证，覆盖三件事：四指张开手势和 `F11` 露出桌面时能否点到、能否拖起截图、拖起后能否放进其他应用。验证结果决定"召唤"是不是取图的主要方式（见 5.5）。用户没有提到使用台前调度，第一版不专门适配。
- **权限提示**：读写 `~/Pictures` 和 `~/Desktop`（导入旧截图时）时，系统可能弹出访问授权。
- **永久删除不可逆**：唯一的安全网是那 5 秒的"捞回"时间，这一段要做得可靠。
- **修改系统截图位置**：如果晾衣绳没在运行，截图会堆进 `~/Pictures/Clothesline/` 根目录，下次启动时要全部补挂上绳（超过绳长就按规则剪断成束）。
